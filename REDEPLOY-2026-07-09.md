## What changed for poems (commits d84f8c4d + 4ba2184a)

The wizard's `导入古诗 (data/poems/)` phase used to fetch from `raw.githubusercontent.com/chinese-poetry/chinese-poetry` and 503'd on prod. Now it reads the prebuilt JSONs that already live in `data/poems-manifest.json` + `data/poems/<id>.json` (1160 per-poem files, all with t2s 简体 + pinyin pre-baked). The transaction wrapper brings the insert from ~83s to ~2s on a single commit at the end.

If the previous deploy showed a `failed: fetch ... → 503` for poems, this fixes it without re-running the wizard (the data was already in `data/poems/`; the table gets mirrored on next init from local JSON).

# 听写练习（出卷 + 报听写）· 设计文档

**Goal:** 老师选一批词条（单字/词语/成语），一键生成**听写卷**（田字格答题纸 + 可选拼音提示）和**答案页**，打印即可上课；课堂上有「报听写」模式：逐条朗读 → 学生在纸上写 → 揭晓答案自评对错，错词一键生成再练卷。听写是中文课每周必做的固定环节，目前站内完全没有。

**Architecture:** 三层，全部增量、不碰现有字帖逻辑。
词条层 `lib/dictation.ts`（纯函数：词条模型、三类来源构建、拼音标注、分页）；
卷面层 `components/dictation/DictationPaper.tsx`（一词条一行：序号 + 拼音行（可选）+ 每字一个田字格，`blank` 答题卷 / `answer` 答案页两种模式，格子复用现有 `WorksheetCell`）；
报听层 `components/dictation/DictationRunner.tsx`（TTS 逐条朗读、间隔自动翻条或手动、揭晓、对/错自评、错词收集 → 一键再出卷）。
入口 `app/dictation/page.tsx`，两个 tab：**出卷** / **报听写**，首页 BentoGrid 加一张卡。

**Tech Stack:** 现有栈内完成：pinyin-pro（词级注音，已在用）、Edge TTS `ReadAloudButton`（已在用）、`WorksheetCell` 田字格（已在用）、浏览器 print（@page + 白名单 CSS，已有惯例）。**零新增依赖。**

**Spec:** 本文档即规格（无外部 spec）。

## Global Constraints

- **只加不改** —— `lib/worksheet-types.ts` 的 `generateLayout`、`WorksheetPreview`、`PracticeTemplate`、`PracticePDF` 现有行为一字不变；`WorksheetCell` 只复用不修改
- **零新增 npm 依赖**
- **多音字由老师定音** —— 拼音提示默认**关闭**；开启后每条拼音**可编辑**，机器注音（pinyin-pro 词级）只作初值。印错注音是教学事故，最终裁决权必须在老师手里
- **屏幕内不写字** —— 不做手写识别（Non-goal）。「报听写」= 听 → 在纸上写 → 揭晓自评；屏幕只负责播音、计时、翻答案、记错词
- **打印走浏览器 print** —— 复用 `@page { size; margin: 1.5cm }` + 现有打印白名单惯例（表单控件 `worksheet-no-print` 不上纸）；本期不做 react-pdf / PNG 导出
- **词条粒度 1~4 字** —— 一条一行；单字、词语（含成语）统一为「词条」
- **一页 10 条**（A4），超出自然分页；本期不接会员门槛（听写卷免费）
- **UI 文案用中文**（与全站一致），代码注释与 commit subject 用英文
- Commit 主题尾加时间戳 `[YYYY-MM-DD HH.MM]`；**不 push**

## Concept

### 当前行为

- 站内练字工具是「字帖」：用户输入内容 → 生成田字格/四线格/横线练习页 → 打印。它是**抄写**工具：范字印在纸上照着写。
- 听写（dictation）没有任何支撑：老师要出听写卷，只能自己用字帖工具凑——字帖没有题号、没有拼音提示、没有答案页、没有报读节奏。
- TTS（`ReadAloudButton`）、HSK 字表、成语库（`data/idioms.json`，378 条，含拼音与释义）都已存在，但没有组合成听写场景。

### 目标行为

1. **出卷**（老师）：选来源（HSK 等级字表 / 成语库 / 自定义粘贴词表）→ 词条列表可增删改、拼音可改 → 选选项（格子类型、拼音提示、姓名栏）→ 预览「答题卷」与「答案页」→ 打印。
2. **报听写**（课堂/自学）：选同一批词条 → 逐条朗读（TTS）→ 可设每条间隔（5/8/12 秒或手动翻条）→ 揭晓该条答案（字 + 拼音）→ 标记对/错 → 结束显示本卷错词，可一键「用错词再出卷」。
3. 答题卷与答案页**编号、顺序、版式 1:1 对应**——同一份词条数据渲染两种模式。

## 设计决策

### 决策 1：双形态并存，卷面优先

听写的真实形态是「老师读、学生写纸上」。所以打印卷是本体，报听写是配套的课堂播放器。屏幕自测再炫，也替代不了纸质卷在海外课堂（一人一张 A4 即上课）的价值。

### 决策 2：三类来源，一视同仁的「词条」

- **HSK 字表**（`data/hsk-vocab.json`，1–5 级单字）→ 单字词条；
- **成语库**（`data/idioms.json`，378 条，`{word, pinyin, meaning, level}`）→ 四字词条；
- **自定义**：老师粘贴课文词表（逗号/空格/换行分隔），按 1~4 字切词条，超过 4 字按逗号/空格拆分后仍超长的**丢弃并在表单提示**（一行田字格（A4 共 8 格）放不下更长的词 + 题号）。

### 决策 3：拼音提示默认关，开启后可逐条编辑

机器注音对多音字（的/了/长）不保证正确。卷子印出去就是教材级的权威，所以：

- 默认不印拼音——听写本就该学生听音写字；
- 初级班需要提示时开启，且**每条拼音是可编辑输入框**，pinyin-pro 的注音只是初值。

### 决策 4：答案页 = 同一版式的 `answer` 模式

答案页与答题卷共用 `DictationPaper`，只有两处不同：格子里填浅灰范字（复用描红的浅灰 + 红边样式约定）且拼音行必显。两页由**同一次 `buildItems()` 结果**渲染，编号顺序不可能漂移。

### 决策 5：报听写不做手写识别

手写识别是另一个产品级课题（识别准确率、输入法、设备差异）。报听写的屏幕职责收敛为四件事：**播音、计时、翻答案、记错词**。学生写字在纸上，揭晓后自己判对错——这正是课堂上老师做的事，自学场景同样成立。

### 决策 6：错词闭环轻量做

一轮报听写结束收集错词 → 「用错词再出卷」生成一张新的听写卷/新一轮报听。完整的间隔重复（艾宾浩斯队列、跨天复习）是独立功能，本期只做**卷内闭环**，不做跨天调度。

### 决策 7：打印只走浏览器 print

`PracticePDF`（react-pdf）为字帖的 5 种版式写了专用渲染器，再为听写卷写一套 PDF 渲染是重投入。听写卷版式简单（题号 + 拼音 + 田字格行），浏览器 print 的 @page 样式已验证可行（字帖就是这么打的）。PDF 导出列入后续路线。

### 决策 8：入口独立成 `/dictation`

听写是教师工具，语义上不是「练字」。首页 BentoGrid 加一张「听写练习」卡，与「练字印帖」「趣味识字游戏」平级。不塞进 `/worksheet` 的 tab——出卷表单、报听写播放器都不是字帖生成器的输入模式。

## Review Focus

以下失败模式必须有测试/走查钉住：

| 输入 / 条件 | 应该得到什么 | 归哪个 Task |
|---|---|---|
| 自定义词表里有超过 4 字的词 | 丢弃并在表单**可见提示**，不静默截断 | Task 1 |
| 多音字词条（「长大」） | 拼音初值可改，改后打印/朗读都用改后的值 | Task 2 |
| 词条表为空 / 全部被丢弃 | 不出卷，空态提示，打印按钮禁用 | Task 2 |
| 答题卷与答案页 | 编号、顺序、条数 1:1 一致 | Task 2 |
| 打印 | 表单控件不上纸；卷面不溢出第二页 | Task 2 + Task 4 |
| TTS 朗读失败（无网络/无语音） | 按钮报错提示，**不阻塞**揭晓/翻条 | Task 3 |
| 错词收集后「再出卷」 | 新一轮只含错词，题号从 1 重新编 | Task 3 |
| 手动翻条模式 | 不自动跳条，节奏完全由老师控制 | Task 3 |

## Verification

### 自动化

- `npx vitest run tests/unit/lib/dictation.test.ts` —— 词条层全绿（拆词、超长告警、注音初值、分页）
- `npx vitest run` —— 全量回归全绿（现有字帖/字帖测试一字不改）
- `npx tsc --noEmit` —— 干净

### 真机 smoke（人工走查）

1. HSK 1 级 10 字出卷：答题卷 10 行空白田字格 + 题号，答案页同版式浅灰范字 + 拼音
2. 自定义粘贴「长大,你好,不可能,中华人民共和国」：前三条进卷，第四条被丢弃且表单提示
3. 开拼音提示、改某条拼音（多音字）：预览与打印用改后的拼音
4. 打印：表单控件不上纸、卷面 ≤ 1 页 A4
5. 报听写：播音正常、间隔自动翻条、手动模式不跳条、揭晓显示答案、标记对错、轮末错词再出卷只含错词
6. TTS 断网降级：报错提示但可继续翻条/揭晓

## Notes / Risks

- **pinyin-pro 对多音字的词级注音不保证正确** —— 以「可编辑 + 默认关闭」兜底；机器注音只是省老师打字的初值。
- **`hsk-vocab.json` 是单字表**（按级别分组的 `{char}`），没有词——所以「词语听写」本期靠自定义粘贴与成语库供给；自动组词（从 bigrams/词频导出常用词表）列入后续路线。
- **一页 10 条是 A4 预设**：A3/B5 本期不为听写卷单独调版（页宽与格子数沿用 `worksheet-page-count` 口径），后续按需加。
- **报听写的节奏参数**（间隔秒数）先做固定 3 档 + 手动，不做自由滑杆——课堂上可预测比可调更重要。
- 与字帖的关系：**完全并列**，不共享 generateLayout；田字格仅复用 `WorksheetCell` 渲染，避免把听写的行模型（题号+拼音+词）塞进字帖的平铺 cell 流里。
